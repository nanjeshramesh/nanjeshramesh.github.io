fivetran/great_expectations

Merged

Pin UTF-8 encoding on filesystem-backed store reads

Fixed a locale-dependent bug where store values and the project YAML were written as UTF-8 but read back using whatever encoding the process's ambient locale resolved to, crashing on non-UTF-8 hosts (mainly Windows). Pinned encoding="utf-8" on every affected read/write path and added tests that force a non-UTF-8 locale to prove the fix.

Fix query asset SQL wrapping so a trailing comment doesn't break validation

Traced a validation failure to two separate places that wrap a query asset's raw SQL in a subquery, one using a plain TextClause and one building the same kind of subquery a different way.
